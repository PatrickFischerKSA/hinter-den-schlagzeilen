# Hinter den Schlagzeilen

Interaktive Lernlandschaft zum Film `Hinter den Schlagzeilen`.

## Enthalten

- Videoeinbindung über den bereitgestellten Dropbox-Link
- Filmnotizen mit Zeitmarken
- Inhaltsquiz mit Sofortfeedback
- Recherche-Labor mit Methodenordnung, Quellen-Triage und Rechercheplan
- Medienethik-Dilemmata mit Begründungsfeldern
- Transferfragen, Produktionsaufträge und Portfolio-Druckansicht

## Öffnen

Die Seite ist statisch gebaut und kann direkt über `index.html` oder über einen lokalen Server geöffnet werden.

Die lokale MP4-Datei ist bewusst nicht Teil des GitHub-Repositorys, weil sie die normale GitHub-Dateigrenze deutlich überschreitet.
